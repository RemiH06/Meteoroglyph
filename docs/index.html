Descripción general

meteoroglyph es una app Android personal para el Nothing Phone 3a que combina clima en tiempo real, calendario de Google y la interfaz Glyph para generar recomendaciones de outfit diarias. Construida completamente en Kotlin con Jetpack Compose, siguiendo la estética metro_theme y la tipografía Ndot-57 de Nothing.

Requisitos de hardware

Optimizada para Nothing Phone 3a (A059) con Nothing OS 4.0 (Android 16). Las funciones Glyph requieren el SDK 2.0 y el dispositivo DEVICE_24111.

Arquitectura

La app sigue una arquitectura MVVM limpia con capas bien separadas.

UI

Capa de UI — Jetpack Compose

HomeScreen, SettingsScreen, FluidMatrixView, GlyphRenderer, widgets Glance. Todo el estado viene del ViewModel via StateFlow.

VM

ViewModels

HomeViewModel orquesta clima, calendario, outfit y Glyph. SettingsViewModel persiste configuración via DataStore.

DA

Capa de datos

WeatherRepository (Open-Meteo), CalendarRepository (CalendarContract), GlyphRepository (JSON assets), SettingsRepository (DataStore), LocationRepository (FusedLocation).

BG

Background

WeatherCheckWorker (WorkManager diario), EventAlarmScheduler + EventAlarmReceiver (AlarmManager exacto por evento), BootReceiver.

Módulos principales

OutfitEngine

Motor de recomendación de ropa. Recibe un WeatherState y los umbrales configurados en AppSettings y devuelve una lista de OutfitItem con tres estados posibles.

EstadoColorSignificado
RECOMMENDEDverdePrenda adecuada para el clima actual
CONDITIONALámbarLlevar con precaución (ej. paraguas si hay 40% lluvia)
BLOCKEDrojoNo recomendado (ej. sandalias si llueve)
NEUTRALgrisIrrelevante para las condiciones actuales

GlyphRepository + GlyphRenderer

Sistema de iconografía custom basado en matrices de puntos JSON creadas con GlyphFactory. El repositorio parsea los archivos desde assets/glyphs/ y los cachea en memoria. El renderer dibuja cada glifo en un Canvas de Compose con círculos para cada punto activo.

// Cargar y renderizar un glifo
val repo  = GlyphRepository(context)
val glyph = repo.getGlyph("weather", "rain")

GlyphRenderer(
    glyph    = glyph,
    tint     = AccentGreen,   // null = colores originales del JSON
    modifier = Modifier.size(48.dp)
)

FluidSimulation (SPH)

Motor de física de fluidos basado en Smoothed Particle Hydrodynamics. Simula N partículas en un espacio 2D circular con fuerzas de presión, viscosidad y gravedad adaptativa según el acelerómetro.

ParámetroVariableDescripciónRango
LlenadofillRatioFracción del recipiente llena0.1 – 2.0
Viscosidadviscosity (μ)Resistencia al movimiento0.01 – 2.0
Rigidezstiffness (k)Compresibilidad del fluido0.1 – 5.0
ReboterestitutionElasticidad en colisión con paredes0.0 – 1.0
Radio suavizadosmoothingRadius (h)Influencia entre partículas1.0 – 5.0
PartículasparticleCount (N)Número de partículas10 – 200
Comportamiento horizontal

Cuando el teléfono está boca arriba o boca abajo, |az| domina sobre ax y ay. El controlador detecta esto y aplica una fuerza centrífuga suave que distribuye las partículas uniformemente por el anillo, reduciendo el brillo proporcionalmente al fillRatio.

Sistema de glifos

Todos los íconos de la app son matrices de puntos diseñadas en GlyphFactory y exportadas como JSON. El formato es:

{
  "name": "rain",
  "category": "weather",
  "cols": 12, "rows": 12,
  "palette": ["#00e5a0", "#f5a623", ...],
  "data": [[null, 3, null, ...], ...]  // null = vacío, Int = índice paleta
}

Notificaciones

Dos tipos de notificaciones enriquecidas con RemoteViews, tipografía Ndot-57 renderizada como Bitmap y glifos de clima como íconos.

Resumen diario WorkManager

Se programa a la hora configurada en Settings. Muestra temperatura, condición, ventana de lluvia, hasta 4 prendas recomendadas y sugerencia de transporte.

Alerta de evento AlarmManager exacto

Se programa 1 hora antes de cada evento del calendario que esté fuera de casa. Misma estructura visual que el resumen diario pero personalizada para el evento específico.

Ícono dinámico

La app cambia su ícono del launcher automáticamente según la condición climática usando ActivityAlias. Hay 11 estados con variantes de modo claro y oscuro generadas por script Python desde los JSON de glifos.
